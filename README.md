# Responsive College Event Portal

## Project Overview

The **Responsive College Event Portal** is a front-end web application developed to provide students with a simple and organized platform to explore and participate in college festival events.

The portal brings important event information such as event details, schedules, announcements, registration, gallery, and contact information into a single responsive website.

## Project Objective

The main objective of this project is to develop a responsive college event portal using HTML5, CSS3, and JavaScript.

The website is designed to:

- Provide information about college festival events
- Display event schedules and announcements
- Allow students to register for events
- Provide a gallery for event highlights
- Allow students to submit enquiries
- Work smoothly across desktop, tablet, and mobile devices

---

## Development Process

The project was developed step by step, starting from the basic website structure and gradually adding styling, responsiveness, and JavaScript functionality.

### 1. Website Structure

The basic structure of the portal was created using **HTML5**.

The website was organized into different sections:

- Home
- Events
- Schedule
- Gallery
- Registration
- Contact
- Footer

Navigation links were added so users can easily move between the different sections.

### 2. Home Page

A homepage was created to introduce the college festival.

It includes:

- Festival title and welcome section
- Featured events
- Latest announcements
- Navigation to important sections

### 3. Event Section

An event listing section was developed to display college festival activities.

Each event provides information such as:

- Event name
- Date
- Time
- Venue
- Description
- Registration option

Registration buttons were also added so that students can directly select an event and move to the registration section.

### 4. Schedule Section

A structured schedule was created to display event timings and venues.

This helps students easily understand when and where each event takes place.

### 5. Registration Form

A student registration form was created with fields for:

- Name
- Email
- Mobile number
- Department
- Year
- Event selection

JavaScript was then used to validate the form before displaying a successful registration message.

### 6. Gallery Section

A responsive gallery was added to display images related to college events and festival activities.

The gallery layout was designed to adjust according to the available screen size.

### 7. Contact Section

A contact and enquiry form was added for students to submit their queries.

The form contains fields such as:

- Name
- Email
- Message

JavaScript validation was implemented to ensure that the required fields are completed.

### 8. CSS Styling

After creating the HTML structure, **CSS3** was used to design the portal.

The styling includes:

- Navigation bar
- Hero section
- Event cards
- Buttons
- Forms
- Schedule table
- Gallery
- Footer
- Spacing and typography

A clean and consistent layout was maintained throughout the website.

### 9. Responsive Design

Responsive design was implemented using **CSS media queries**.

The layout was adjusted for:

- Desktop
- Laptop
- Tablet
- Mobile

Elements such as navigation, event cards, forms, tables, and gallery images automatically adjust according to the screen size.

### 10. JavaScript Functionality

JavaScript was used to make the website interactive.

The main functionality includes:

- Registration form validation
- Contact form validation
- Required field checking
- Dynamic announcements
- Event selection
- DOM manipulation
- Event listeners
- Success messages
- Error messages
- Smooth navigation to the registration section

### 11. Testing

The website was tested locally using **Visual Studio Code and Live Server**.

The different sections and interactive features were checked to ensure that:

- Navigation works correctly
- Forms validate required fields
- Event registration buttons work
- Responsive layouts display correctly
- JavaScript interactions work as expected

### 12. Version Control

After completing the project, **Git** was used for version control.

The project was initialized as a Git repository, the project files were added, and an initial commit was created.

The repository was then connected to GitHub and the project was pushed to the `main` branch.

### 13. Deployment

The completed project was deployed using **GitHub Pages**.

The `main` branch was selected as the publishing source, allowing the `index.html` file to be hosted as a public website.

The final deployed website can be accessed here:

**https://muthukoornandini.github.io/responsive-college-event-portal/**
